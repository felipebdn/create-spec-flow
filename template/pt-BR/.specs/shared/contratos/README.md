# Contratos compartilhados por área

Arquivos daqui são contratos reutilizados por mais de uma mudança, mas não são contexto obrigatório.
Leia somente os contratos citados pela mudança ou materialmente relacionados ao domínio tocado.

Quando `shared/convencoes.md` passar de aproximadamente 400 linhas, extraia uma área coerente para
este diretório e deixe em convenções apenas o índice e a regra que aponta para ela.
