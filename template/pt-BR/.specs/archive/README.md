# archive

Mudanças concluídas e verificadas, movidas para fora da fila ativa.

Nada aqui é apagado. Uma mudança arquivada continua sendo a explicação de por que
o código está do jeito que está — é o material que a próxima pessoa (ou a próxima
sessão de agente) lê quando pergunta "por que fizeram assim?".

Uma mudança arquivada descreve o código **no momento em que foi escrita**. Nunca
leia uma pasta daqui como se fosse o estado atual do sistema; para isso, leia o
código e o `.specs/memory/`.

Arquivamento é feito pela skill `spec-arquivar-mudanca`, por decisão explícita do
usuário — nunca automaticamente pelo `EXECUTAR-TODAS.md`.
